# 🚀 3D Space-Themed Animated Birthday Card

An interactive, responsive, and beautifully animated 3D space-themed birthday greeting card created using **HTML, CSS (Vanilla), and JavaScript**. It features floating space objects, realistic 3D metallic balloons, a dancing furry astronaut, and interactive background music/voice support.

---

## ✨ Features

* **🌌 Dynamic Nebula & Starfield:** Randomly generated twinkling stars with depth variation.
* **🕺 Animated 3D Furry Astronaut:** A cute, blue fuzzy-textured astronaut dancing dynamically at the center.
* **🎈 Metallic Glossy Balloons:** Beautiful 3D metallic balloons that sway gently as if floating in space.
* **🛸 Floating Space Objects:** Interactive animated Saturn, UFO, and a rocket crossing the screen.
* **🎵 Smart Audio Player:** Background voice/music support with auto-fallback to an online track if the local file is missing.
* **📱 100% Fully Responsive:** Beautifully auto-scales to fit perfectly on both Mobile and Desktop screens.

---

## 🛠️ Tech Stack Used

* **HTML5** (Structure & Audio API)
* **CSS3** (3D Transforms, Custom Animations, Media Queries, and Realistic Fur Texturing)
* **JavaScript** (Dynamic Starfield Generation and Browser-compliant Audio Playback)
